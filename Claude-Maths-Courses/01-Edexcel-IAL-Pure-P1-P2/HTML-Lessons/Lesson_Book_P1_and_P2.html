Algebraic Expressions

P1 — Ch 1

Key formulas

  • am · an = am+n,   am / an = am−n,   (am)n = amn
  • a0 = 1,   a−n = 1an,   am/n = (n√a)m
  • (a ± b)2 = a2 ± 2ab + b2,   (a + b)(a − b) = a2 − b2
  • ab = a b   (rationalise with the conjugate a − b)
Algebra is the grammar of everything that follows, so the goal here is speed without thought. Index laws only combine powers of the same base under multiplication and division — never under addition. Factorising is just expanding in reverse: a product equals a sum. Surds are kept exact (never rounded), and a denominator should never be left with a surd in it — clear it using the conjugate.

Worked examples

Example 1 — fractional index.
163/4 = (4√16)3 = 23 = 8. Do the root first, then the power.
Example 2 — factorise 3x2 + 10x + 8.
a·c = 24; split 10x = 6x + 4x:  3x2 + 6x + 4x + 8 = 3x(x + 2) + 4(x + 2) = (3x + 4)(x + 2).
Example 3 — rationalise 64 − 2.
Multiply by (4 + 2): denominator 16 − 2 = 14, numerator 24 + 62 ⇒ 12 + 327.

Practice

  1. Simplify (2x4)3.
  2. Evaluate 82/3.
  3. Expand (x + 5)(x − 3).
  4. Factorise x2 + 2x − 15.
  5. Simplify 48.
  6. Rationalise 63.
Answers: 1) 8x12   2) 4   3) x2 + 2x − 15   4) (x + 5)(x − 3)   5) 43   6) 23

Quadratics

P1 — Ch 2

Key formulas

  • Quadratic formula: x = −b ± b2 − 4ac2a
  • Completed square: x2 + bx + c = (x + b2)2 − (b2)2 + c; vertex from a(x − h)2 + k is (h, k)
  • Discriminant Δ = b2 − 4ac:  Δ > 0 two roots, Δ = 0 one, Δ < 0 none
A quadratic is a parabola. Factorising and the formula find where it meets the x-axis; completing the square finds its turning point and is the most useful single skill in P1. The discriminant tells you how many real roots exist without solving — which is exactly what “find the values of k…” questions test. Some equations are quadratics in disguise: substitute a letter for the repeated chunk.

Worked examples

Example 1 — complete the square 2x2 − 12x + 7.
2(x2 − 6x) + 7 = 2[(x − 3)2 − 9] + 7 = 2(x − 3)2 − 11; vertex (3, −11).
Example 2 — discriminant.
x2 + kx + 9 = 0 has equal roots ⇒ k2 − 36 = 0 ⇒ k = ±6.
Example 3 — hidden quadratic.
x4 − 5x2 + 4 = 0, let u = x2: (u − 1)(u − 4) = 0 ⇒ x = ±1, ±2.

Practice

  1. Solve x2 − 5x + 6 = 0.
  2. Solve 3x2 − x − 2 = 0.
  3. Complete the square: x2 + 6x + 5; state the vertex.
  4. How many real roots has x2 − 4x + 4 = 0?
  5. Find k for which 2x2 + kx + 2 = 0 has equal roots.
Answers: 1) x = 2, 3   2) x = 1, −2/3   3) (x + 3)2 − 4, vertex (−3, −4)   4) one repeated root (x = 2)   5) k = ±4

Equations and Inequalities

P1 — Ch 3

Key ideas

  • Linear + quadratic simultaneously: substitute the linear into the quadratic.
  • Multiplying/dividing an inequality by a negative flips the sign.
  • Quadratic inequality (a > 0): > 0 ⇒ outside the roots; < 0 ⇒ between the roots.
Two equations solved together are the points where two graphs meet; a line and a curve meet where substitution gives a quadratic (and the discriminant tells you whether they cross, touch, or miss). Inequalities work like equations with one trap — flipping on a negative — and quadratic inequalities are read off a quick parabola sketch, giving either a single interval “between” or two intervals “outside”.

Worked examples

Example 1 — line and circle.
y = x + 1, x2 + y2 = 25 ⇒ 2x2 + 2x − 24 = 0 ⇒ (x + 4)(x − 3) = 0: points (−4, −3), (3, 4).
Example 2 — quadratic inequality.
x2 − x − 6 > 0 ⇒ (x − 3)(x + 2) > 0 ⇒ x < −2 or x > 3 (outside the roots).

Practice

  1. Solve x + y = 5, x − y = 1.
  2. Solve y = x + 1 and y = x2 − 1.
  3. Solve 2x + 3 > 7.
  4. Solve x2 − 4 < 0.
  5. Solve x2 − 2x − 3 ≥ 0.
Answers: 1) x = 3, y = 2   2) (2, 3), (−1, 0)   3) x > 2   4) −2 < x < 2   5) x ≤ −1 or x ≥ 3

Graphs and Transformations

P1 — Ch 4

Key ideas

  • Outside f acts on y (as expected); inside f acts on x (the opposite way).
  • f(x) + a up a;  f(x + a) left a;  af(x) stretch ×a vertically;  f(ax) stretch ×1/a horizontally.
  • −f(x) reflect in the x-axis;  f(−x) reflect in the y-axis.
  • Repeated factor (x − a)2 ⇒ the curve touches the axis at x = a.
To sketch a polynomial, find the axis crossings (each factor zero), the y-intercept, and the end behaviour from the leading term; a squared factor means the curve bounces off the axis rather than crossing. Transformations are best applied to the key points (intercepts and turning points) — and the one thing to burn in is that horizontal shifts go the opposite way to the sign inside the bracket.

Worked examples

Example 1 — sketch data for y = (x + 1)(x − 2)(x − 3).
Crosses at x = −1, 2, 3; y-intercept (0, 6); positive cubic (rises to the right).
Example 2 — transformation.
y = x2 → y = (x − 3)2 + 2 is a shift right 3, up 2; the vertex moves (0, 0) → (3, 2).

Practice

  1. Where does y = (x − 1)(x + 3) cross the axes?
  2. Describe y = f(x) → y = f(x) − 3.
  3. Describe y = f(x) → y = f(x + 2).
  4. State the vertex of y = (x + 1)2 − 2.
  5. Describe y = x2 → y = −x2.
Answers: 1) x-axis at 1, −3; y-axis at (0, −3)   2) down 3   3) left 2   4) (−1, −2)   5) reflection in the x-axis

Straight-Line Graphs

P1 — Ch 5

Key formulas

  • Gradient m = y2 − y1x2 − x1;   line: y − y1 = m(x − x1)
  • Midpoint (x1+x22, y1+y22);   distance (x2−x1)2 + (y2−y1)2
  • Parallel: equal gradients.   Perpendicular: m1 m2 = −1 (negative reciprocal).
Everything about a straight line comes from its gradient and one point. The form y − y1 = m(x − x1) handles almost every question. The single most-tested idea is perpendicularity: the gradient you need is the negative reciprocal — flip it and change the sign. When a question asks for ax + by + c = 0, clear all fractions at the end.

Worked examples

Example 1 — perpendicular line.
Through (2, 5) perpendicular to y = 3x − 1: new gradient −1/3, so y − 5 = −⅓(x − 2) ⇒ x + 3y − 17 = 0.
Example 2 — distance.
From (1, 2) to (4, 6): 32 + 42 = 25 = 5.

Practice

  1. Gradient through (0, 0) and (4, 8).
  2. Equation through (1, 1) with gradient 2 (as y = mx + c).
  3. Gradient of any line perpendicular to y = 2x + 3.
  4. Midpoint of (2, 4) and (6, 10).
  5. Distance from (0, 0) to (3, 4).
Answers: 1) 2   2) y = 2x − 1   3) −1/2   4) (4, 7)   5) 5

Trigonometric Ratios

P1 — Ch 6

Key formulas

  • Sine rule: asin A = bsin B = csin C
  • Cosine rule: a2 = b2 + c2 − 2bc cos A
  • Area = ½ ab sin C
  • Exact: sin 30° = ½, cos 30° = 32, tan 45° = 1, sin 60° = 32
Use the sine rule when you have a side paired with its opposite angle, and the cosine rule for three sides or for two sides and the angle between them. The area formula needs two sides and the included angle. Keep the calculator in degree mode for this chapter, and learn the exact values — examiners love them.

Worked examples

Example 1 — cosine rule.
a = 8, b = 5, C = 60°: c2 = 64 + 25 − 2(8)(5)cos 60° = 89 − 40 = 49 ⇒ c = 7.
Example 2 — area.
Sides 7 and 9, included angle 40°: ½(7)(9)sin 40° ≈ 20.2.

Practice

  1. a = 5, b = 7, C = 60°. Find c (2 d.p.).
  2. Area of a triangle with sides 6 and 10 and included angle 30°.
  3. Exact value of sin 30° + cos 60°.
  4. Solve sin x = 22 for 0 ≤ x < 360°.
  5. Exact value of tan 45° + sin 30°.
Answers: 1) c = 39 ≈ 6.24   2) 15   3) 1   4) x = 45°, 135°   5) 1.5

Trigonometric Identities and Equations

P1 — Ch 7

Key formulas

  • sin2θ + cos2θ = 1   (so sin2θ = 1 − cos2θ)
  • tan θ = sin θcos θ
  • Second solution: sine → 180° − θ;   cosine → 360° − θ;   tangent repeats every 180°.
Two identities carry the whole chapter. To prove an identity, work on one side only until it becomes the other. To solve an equation, isolate the ratio, take the inverse for the first angle, then use the symmetry rules to collect every solution in the range. If sin2 and cos both appear, convert with sin2 = 1 − cos2 so it becomes a quadratic in one ratio.

Worked examples

Example 1 — solve in range.
sin x = ½, 0 ≤ x < 360°: first 30°, then 180° − 30° = 150° ⇒ x = 30°, 150°.
Example 2 — quadratic in sine.
2 sin2x + sin x − 1 = 0 ⇒ (2 sin x − 1)(sin x + 1) = 0 ⇒ sin x = ½ or −1 ⇒ x = 30°, 150°, 270°.

Practice

  1. Solve cos x = 0.5, 0 ≤ x < 360°.
  2. Solve tan x = 3, 0 ≤ x < 360°.
  3. Solve 2 sin x − 1 = 0, 0 ≤ x < 360°.
  4. Prove cos x · tan x = sin x.
  5. Solve sin2x − sin x = 0, 0 ≤ x < 360°.
Answers: 1) 60°, 300°   2) 60°, 240°   3) 30°, 150°   4) cos x(sin x / cos x) = sin x ■   5) 0°, 90°, 180°

Differentiation

P1 — Ch 8

Key formulas

  • ddx (xn) = n xn−1   (differentiate term by term)
  • Tangent gradient = f′(a);   normal gradient = −1 / f′(a)
  • Stationary: f′(x) = 0;   f″ > 0 minimum, f″ < 0 maximum
  • Increasing where f′(x) > 0, decreasing where f′(x) < 0
The derivative is the gradient of the curve at each point. Bring the power down and reduce it by one — but first rewrite roots and fractions as powers (x = x1/2, 1/x = x−1). Setting the derivative to zero finds turning points; the second derivative tells you which is a peak and which is a valley.

Worked examples

Example 1 — tangent.
y = x2 at x = 3: point (3, 9), f′(3) = 6; tangent y − 9 = 6(x − 3) ⇒ y = 6x − 9.
Example 2 — stationary points.
y = x3 − 3x2: f′ = 3x(x − 2) = 0 ⇒ x = 0, 2; f″ = 6x − 6 ⇒ max (0, 0), min (2, −4).

Practice

  1. Differentiate y = 5x2 − 3x.
  2. Differentiate y = x3 + 2x.
  3. Gradient of y = x2 at x = 4.
  4. Find and classify the stationary point of y = x2 − 6x + 1.
  5. Differentiate y = 1x.
Answers: 1) 10x − 3   2) 3x2 + 2   3) 8   4) (3, −8), minimum   5) −1/x2

Integration

P1 — Ch 9

Key formulas

  • ∫ xn dx = xn+1n + 1 + C  (n ≠ −1) — always + C for indefinite
  • Definite: ∫ab f(x) dx = F(b) − F(a)
  • Area under a curve (above the axis) = ∫ab y dx
Integration reverses differentiation: raise the power by one and divide by the new power. The constant + C matters for indefinite integrals and is found from a point on the curve. A definite integral has limits, needs no + C, and measures the area between the curve and the x-axis — with the warning that area below the axis comes out negative, so split at the roots.

Worked examples

Example 1 — indefinite.
∫(3x2 − 4x + 1) dx = x3 − 2x2 + x + C.
Example 2 — area.
Area under y = x2 from 0 to 3: [x3/3]03 = 9.

Practice

  1. Find ∫ 4x3 dx.
  2. Find ∫ (2x + 1) dx.
  3. Evaluate ∫01 3x2 dx.
  4. Evaluate ∫12 2x dx.
  5. A curve has dydx = 2 and passes through (1, 5). Find y.
Answers: 1) x4 + C   2) x2 + x + C   3) 1   4) 3   5) y = 2x + 3

Algebraic Methods

P2 — Ch 1

Key ideas

  • Remainder theorem: dividing f(x) by (x − a) leaves remainder f(a).
  • Factor theorem: (x − a) is a factor ⇔ f(a) = 0.
  • To factorise a cubic: find one root by trial, divide it out, factorise the quadratic.
This lesson is about polynomials beyond quadratics. The factor theorem is the key that unlocks cubics: test small values until one gives zero, which hands you a linear factor; divide and you are left with a quadratic you already know how to crack. The remainder theorem is the same evaluation idea used to find what is left over without doing the full division. Algebraic fractions simplify by factorising top and bottom and cancelling.

Worked examples

Example 1 — factor theorem.
f(x) = x3 − 3x2 − x + 3: f(1) = 0 so (x − 1) is a factor ⇒ (x − 1)(x − 3)(x + 1).
Example 2 — remainder.
f(x) = x3 + 2x2 − 3x + 4 ÷ (x − 2): remainder f(2) = 8 + 8 − 6 + 4 = 14.

Practice

  1. Remainder when x3 + 1 is divided by (x − 1).
  2. Is (x − 2) a factor of x3 − 8?
  3. Simplify x2 − 1x + 1.
  4. Remainder when x2 − 3x + 2 is divided by (x + 2).
  5. Factorise x3 − x.
Answers: 1) 2   2) yes (f(2) = 0)   3) x − 1   4) 12   5) x(x − 1)(x + 1)

Circles

P2 — Ch 2

Key formulas

  • Circle, centre (a, b), radius r: (x − a)2 + (y − b)2 = r2
  • General form: complete the square in x and y to find centre and radius.
  • The tangent is perpendicular to the radius at the point of contact.
A circle equation is just Pythagoras around a centre. Given the messy general form, completing the square in both variables recovers the centre and radius. Most circle problems then reduce to one fact: the radius to a point and the tangent there are perpendicular, so their gradients multiply to −1.

Worked examples

Example 1 — centre and radius.
x2 + y2 − 6x + 4y − 12 = 0 ⇒ (x − 3)2 + (y + 2)2 = 25: centre (3, −2), radius 5.
Example 2 — tangent.
Centre (3, −2), point P(6, 2): radius gradient 4/3, tangent gradient −3/4 ⇒ 3x + 4y − 26 = 0.

Practice

  1. Centre and radius of (x − 1)2 + (y − 2)2 = 16.
  2. Centre and radius of x2 + y2 − 4x − 6y + 9 = 0.
  3. Does (5, 0) lie on (x − 1)2 + y2 = 16?
  4. Gradient of the tangent at (3, 4) to a circle centred at the origin.
Answers: 1) centre (1, 2), radius 4   2) (x − 2)2 + (y − 3)2 = 4: centre (2, 3), radius 2   3) yes (16 = 16)   4) −3/4

Exponentials and Logarithms

P2 — Ch 3

Key formulas

  • loga x = y ⇔ ay = x;   ln x = loge x
  • log(xy) = log x + log y,   log(x/y) = log x − log y,   log(xk) = k log x
  • To solve ax = b: x = log b / log a (or take ln).
A logarithm answers “what power?”. The three laws turn products into sums, quotients into differences, and powers into multipliers — which is how exponential equations get solved: take logs of both sides and the unknown power comes down. Always reject solutions that would require the log of zero or a negative number.

Worked examples

Example 1 — solve.
3x = 20 ⇒ x = ln 20 / ln 3 ≈ 2.73.
Example 2 — log laws.
2 log x − log 3 = log 12 ⇒ log(x2/3) = log 12 ⇒ x2 = 36 ⇒ x = 6 (reject −6).

Practice

  1. Solve 2x = 8.
  2. Evaluate log3 81.
  3. Write log 6 + log 2 as a single logarithm.
  4. Solve 10x = 50 (2 d.p.).
  5. Evaluate ln e3.
Answers: 1) x = 3   2) 4   3) log 12   4) x ≈ 1.70   5) 3

The Binomial Expansion

P2 — Ch 4

Key formulas

  • (a + b)n = Σ nCr an−r br
  • nCr = n!r!(n − r)!  (the nCr button)
  • The term in br is nCr an−r br.
The binomial theorem expands a bracket raised to a power without multiplying it out by hand. Each term pairs a Pascal/nCr coefficient with falling powers of the first term and rising powers of the second. For a single coefficient you don’t expand everything — you jump straight to the term you need, and you must include the powers of any number inside the bracket.

Worked examples

Example 1 — full expansion.
(2 + x)4 = 16 + 32x + 24x2 + 8x3 + x4.
Example 2 — single coefficient.
Coefficient of x3 in (1 + 2x)5: 5C3 (2x)3 = 10 · 8x3 ⇒ 80.

Practice

  1. Expand (1 + x)4.
  2. Coefficient of x2 in (1 + x)6.
  3. Expand (2 + x)3.
  4. Coefficient of x3 in (1 + 3x)4.
Answers: 1) 1 + 4x + 6x2 + 4x3 + x4   2) 15   3) 8 + 12x + 6x2 + x3   4) 108

Sequences and Series

P2 — Ch 5

Key formulas

  • Arithmetic: un = a + (n − 1)d;   Sn = n2[2a + (n − 1)d]
  • Geometric: un = a rn−1;   Sn = a(1 − rn)1 − r
  • Sum to infinity (|r| < 1): S∞ = a1 − r
Arithmetic sequences add a fixed amount each step; geometric ones multiply by a fixed ratio. Identify the first term and the difference or ratio, then choose the right formula. A geometric series only has a finite sum to infinity when the ratio is between −1 and 1, where the terms shrink to nothing.

Worked examples

Example 1 — arithmetic.
a = 3, d = 5: 10th term = 3 + 9(5) = 48; S10 = 5(2·3 + 9·5) = 255.
Example 2 — sum to infinity.
a = 8, r = ½ ⇒ S∞ = 8 / (1 − ½) = 16.

Practice

  1. Arithmetic a = 2, d = 4: the 10th term.
  2. Same sequence: S10.
  3. Geometric a = 1, r = 2: the 8th term.
  4. Same sequence: S8.
  5. Geometric a = 9, r = 13: the sum to infinity.
Answers: 1) 38   2) 200   3) 128   4) 255   5) 13.5

Radian Measure

P2 — Ch 6

Key formulas

  • π rad = 180°
  • Arc length s = rθ;   sector area A = ½ r2θ  (θ in radians)
  • Segment area = ½ r2(θ − sin θ)
Radians measure angle by arc length rather than degrees, which makes the arc and sector formulas beautifully simple — but they only work in radians, so convert first and switch the calculator to radian mode. A sector is a “pizza slice”; subtract the triangle from it to get a segment.

Worked examples

Example 1 — arc and sector.
r = 6, θ = 1.2: arc = 6(1.2) = 7.2; area = ½(36)(1.2) = 21.6.
Example 2 — convert.
60° = 60 × π/180 = π/3 rad.

Practice

  1. Convert 90° to radians.
  2. Convert π/3 to degrees.
  3. Arc length for r = 5, θ = 2.
  4. Sector area for r = 5, θ = 2.
  5. Convert 270° to radians.
Answers: 1) π/2   2) 60°   3) 10   4) 25   5) 3π/2

Differentiation (Optimisation)

P2 — Ch 7

Method — optimisation

  • Write the quantity to optimise as a formula.
  • Use the constraint to reduce it to one variable.
  • Differentiate, set = 0, solve; justify max/min with f″.
  • Answer the real question (often the value, not just x).
Optimisation applies the differentiation you already know to real shapes: maximise an area or volume, or minimise material. The art is the setup — write the target, then use the given constraint to eliminate a variable so you have a function of one thing to differentiate. Setting the derivative to zero finds the optimum; the second derivative confirms it’s the max or min you want.

Worked examples

Example 1 — maximise area.
40 m of fence, three sides: 2x + y = 40 ⇒ A = x(40 − 2x) = 40x − 2x2; A′ = 40 − 4x = 0 ⇒ x = 10, y = 20; max area 200 m2.
Example 2 — turning points.
y = x3 − 3x: f′ = 3x2 − 3 = 0 ⇒ x = ±1; min (1, −2), max (−1, 2).

Practice

  1. Find and classify the stationary point of y = x2 − 4x + 1.
  2. A rectangle has perimeter 20. Find the maximum area.
  3. Find the stationary points of y = x3 − 3x and their nature.
Answers: 1) (2, −3), minimum   2) 5 × 5 = 25   3) min (1, −2), max (−1, 2)

Integration (Area & Trapezium Rule)

P2 — Ch 8

Key formulas

  • Area between a curve and a line = ∫ (top − bottom) dx between intersection points.
  • Trapezium rule: ∫ab y dx ≈ h2[y0 + yn + 2(y1 + … + yn−1)],   h = (b − a)/n
This extends integration to areas trapped between two graphs (integrate the upper minus the lower across their meeting points) and to curves you cannot integrate exactly, where the trapezium rule slices the area into strips and adds their areas. The one thing students forget: the first and last heights are not doubled, and h is the strip width, found by dividing the interval by the number of strips.

Worked examples

Example 1 — area between graphs.
y = x2 and y = x + 2 meet at x = −1, 2; area = ∫−12[(x + 2) − x2] dx = 4.5.
Example 2 — trapezium rule.
∫14 (1/x) dx, 3 strips, ordinates 1, 0.5, 0.333, 0.25: ≈ ½[1.25 + 2(0.833)] ≈ 1.46.

Practice

  1. Evaluate ∫02 x dx.
  2. Area under y = x2 from 0 to 2.
  3. Evaluate ∫14 x−1/2 dx.
  4. Trapezium rule, 2 strips, for ∫02 x2 dx.
Answers: 1) 2   2) 8/3   3) [2x]14 = 2   4) 3 (exact 8/3 ≈ 2.667)
