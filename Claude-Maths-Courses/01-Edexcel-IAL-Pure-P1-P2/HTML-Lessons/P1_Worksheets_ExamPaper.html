Pure Mathematics 1 — Worksheets 1–9

Worksheet 1 · Algebraic Expressions

  1. (3x3)2 = 9x6 ⇒ 9x6 · x5 = 9x11.
  2. x5−2y2−5 = x3y−3 = x3y3.
  3. 272/3 = (271/3)2 = 32 = 9.
  4. 32−2/5 = 1 / (321/5)2 = 1 / 22 = 1/4.
  5. 8a6b34a3b2 = 2a3b.
  6. 6x2 + 15x − 4x − 10 = 6x2 + 11x − 10.
  7. 4x2 − 20x + 25.
  8. (x − 4)(x − 5).
  9. (2x − 5)(2x + 5).
  10. (3x − 1)(2x + 3).
  11. 72 = 36·2 = 62.
  12. 33 + 53 − 23 = 63.
  13. 6 − 35 + 25 − 5 = 1 − 5.
  14. 147 = 1477 = 27.
  15. Multiply by the conjugate (3 − 2): denominator 9 − 2 = 7, giving 3 − 27.

Worksheet 2 · Quadratics

  1. (x − 2)(x − 5) = 0 ⇒ x = 2, 5.
  2. (x + 7)(x − 4) = 0 ⇒ x = −7, 4.
  3. (2x − 1)(x + 3) = 0 ⇒ x = ½, −3.
  4. (3x − 4)(3x + 4) = 0 ⇒ x = ±4/3.
  5. (x + 4)2 − 13; vertex (−4, −13).
  6. (x − 5/2)2 − 17/4; vertex (5/2, −17/4).
  7. 3(x + 2)2 − 13; vertex (−2, −13).
  8. Δ = 25 + 8 = 33, x = 5 ± 334.
  9. Equal roots ⇒ k2 − 64 = 0 ⇒ k = ±8.
  10. Δ = 9 − 8k > 0 ⇒ k < 9/8, and k ≠ 0.
  11. u = x2: (u − 4)(u − 9) = 0 ⇒ x = ±2, ±3.
  12. u = x: (u − 2)(u − 5) = 0 ⇒ x = 4, 25.
  13. Roots −2, 4; y-int (0, −8); vertex (1, −9).
  14. (k + 3)2 − 16k = k2 − 10k + 9 = (k − 1)(k − 9) = 0 ⇒ k = 1, 9.

Worksheet 3 · Equations and Inequalities

  1. Add: 5x = 15 ⇒ x = 3, y = 2.
  2. 2x2 − 2x − 24 = 0 ⇒ (x − 4)(x + 3) = 0: (4, 3), (−3, −4).
  3. x2 − x − 2 = 0 ⇒ (x − 2)(x + 1) = 0: (2, 4), (−1, 1).
  4. 3x ≤ 12 ⇒ x ≤ 4.
  5. −3x > 9 ⇒ x < −3.
  6. Roots −3, 4; −3 < x < 4.
  7. Roots 2, 3; x ≤ 2 or x ≥ 3.
  8. (2x − 1)(x + 3) ≤ 0: −3 ≤ x ≤ ½.
  9. Δ = k2 − 16 < 0 ⇒ −4 < k < 4.

Worksheet 4 · Graphs and Transformations

  1. x-axis at x = 2, −1, −4; y-axis at (0, −8).
  2. Translation right 4, up 1; vertex (4, 1).
  3. (a) left 3; (b) reflection in the x-axis; (c) vertical stretch ×3.
  4. Crosses at x = −1; touches at x = 2 (repeated factor); y-int (0, 4); positive cubic.
  5. (3, 9).

Worksheet 5 · Straight-Line Graphs

  1. m = 10 − 25 − 1 = 2.
  2. y = 3x − 7.
  3. m = 2, y = 2x − 3.
  4. Perpendicular gradient −½: x + 2y − 11 = 0.
  5. Midpoint (1, 3.5); AB = 16 + 9 = 5.

Worksheet 6 · Trigonometric Ratios

  1. c2 = 64 + 25 − 2(8)(5)cos 60° = 49 ⇒ c = 7.
  2. b = 10 sin 65° / sin 40° ≈ 14.1.
  3. ½(9)(12)sin 35° ≈ 31.0.
  4. 32 + 32 = 3.
  5. x = 30°, 330°.

Worksheet 7 · Trigonometric Identities and Equations

  1. x = 30°, 150°.
  2. x = 45°, 225°.
  3. cos x = −½ ⇒ x = 120°, 240°.
  4. sin x(2 sin x − 1) = 0 ⇒ x = 0°, 180°, 30°, 150°.
  5. sin xtan x = sin x · cos xsin x = cos x. ■
  6. 2(1 − sin2x) + sin x − 1 = 0 ⇒ 2 sin2x − sin x − 1 = 0 ⇒ (2 sin x + 1)(sin x − 1) = 0. So sin x = −½ or 1: x = 210°, 330°, 90°.

Worksheet 8 · Differentiation

  1. dydx = 12x2 − 6x + 7.
  2. y = x1/2 + x−2 ⇒ dydx = ½x−1/2 − 2x−3 = 12x − 2x3.
  3. At x = 3: point (3, −2), f′(x) = 2x − 4, f′(3) = 2; tangent y = 2x − 8.
  4. f′ = 3x2 − 12 = 0 ⇒ x = ±2; f″ = 6x: maximum (−2, 21), minimum (2, −11).
  5. 2x − 6 > 0 ⇒ x > 3.

Worksheet 9 · Integration

  1. 2x3 − 2x2 + 3x + C.
  2. ⅔x3/2 + C.
  3. [x3 + 2x]02 = 8 + 4 = 12.
  4. y = 2x2 − x + C; 3 = 8 − 2 + C ⇒ C = −3; y = 2x2 − x − 3.
  5. [x3/3 + x]03 = 9 + 3 = 12.
