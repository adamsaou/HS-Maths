1

Simplifying Algebraic Fractions

The idea

  • Factorise the top and the bottom fully, then cancel any common factor.
  • You can only cancel whole brackets (things multiplied) — never single terms of a sum.
Example.
x2 − 9x2 + 5x + 6 = (x − 3)(x + 3)(x + 2)(x + 3) = x − 3x + 2  (cancel the common x + 3).
2

Polynomial Long Division

The routine (each step)

  • Divide the leading terms → multiply back → subtract → bring down the next term.
  • Watch the signs on the subtract step (flip & add). Hold a place for any missing power with 0.
  • Alternative: matching coefficients — write f(x) = (x − a)(x2 + bx + c), expand, and match.
Example.
(x3 − 3x2 − x + 3) ÷ (x − 1):
            x²  − 2x  − 3
 x − 1  │  x³ − 3x² −  x + 3
        x³ ÷ x = x²  ; x²(x−1)=x³−x² ; subtract → −2x²  (bring down −x)
        −2x² ÷ x = −2x ; −2x(x−1)=−2x²+2x ; subtract → −3x  (bring down +3)
        −3x ÷ x = −3 ; −3(x−1)=−3x+3 ; subtract → 0  (remainder)
Quotient x2 − 2x − 3 = (x − 3)(x + 1).
3

The Remainder Theorem

Key result

  • When f(x) is divided by (x − a), the remainder is f(a).
  • For a divisor (bx − a), the remainder is f(a/b).
Example.
f(x) = x3 + 2x2 − 3x + 4 divided by (x − 2): remainder = f(2) = 8 + 8 − 6 + 4 = 14. No division needed — just substitute.
4

The Factor Theorem

Key result & method

  • (x − a) is a factor of f(x) if and only if f(a) = 0.
  • To factorise a cubic: test factors of the constant term (try ±1, ±2, …) to find a root, divide it out, then factorise the quadratic.
Example.
Factorise f(x) = x3 − 6x2 + 11x − 6.  f(1) = 0 → (x − 1) a factor; dividing gives x2 − 5x + 6 = (x − 2)(x − 3). So f(x) = (x − 1)(x − 2)(x − 3).
5

Proof

The three tools

  • Deduction: argue directly from known facts (e.g. even = 2n, odd = 2n + 1).
  • Exhaustion: check every possible case.
  • Counterexample: one example that fails disproves a claim.
Example.
Prove the sum of two consecutive integers is odd: n + (n + 1) = 2n + 1, which is odd by definition. ■

Answer Key

Part A — Simplify

  1. (x − 4)(x + 4) / [x(x + 4)] = (x − 4)/x
  2. (x − 4)(x + 3) / [(x − 3)(x + 3)] = (x − 4)/(x − 3)
  3. (2x + 1)(x + 3)/(x + 3) = 2x + 1
  4. (x − 5)(x + 5)/(x − 5)2 = (x + 5)/(x − 5)
  5. 3(x − 2)(x + 2)/(x + 2) = 3(x − 2)

Part B — Quotient

  1. x2 − x − 6 = (x − 3)(x + 2)
  2. x2 + 2x − 3 = (x + 3)(x − 1)
  3. 2x2 + 3x − 2 = (2x − 1)(x + 2)
  4. x2 − x − 6 = (x − 3)(x + 2)

Part C — Remainder (just compute f(a))

  1. f(2) = 8 + 8 − 6 + 4 = 14
  2. f(−1) = −2 − 1 + 5 = 2
  3. f(1) = 1 − 4 + 2 − 1 = −2
  4. f(−3) = −27 + 27 + 6 + 6 = 12

Part D — Factorise

  1. f(1) = 0 ✓; (x − 1)(x − 2)(x − 3)
  2. f(−1) = 0 → (x + 1)(x + 3)(x − 2)
  3. f(2) = 0 → (x − 2)(x − 4)(x + 3)
  4. f(2) = 16 + 4 − 26 + a = 0 → a = 6
  5. f(3) = 0 → (x − 3)(2x − 1)(x + 2)

Part E — Proof

  1. Two consecutive odd numbers: 2n + 1 and 2n + 3. Sum = 4n + 4 = 4(n + 1), a multiple of 4. ■
  2. Counterexample: n = 1 gives 1 + 3 = 4, which is not prime. One failing case disproves it. ■
