## Part A

**1.** `(3x^3)^2 = 9x^6`, then `× x^5 = 9x^11`. → **`9x^11`**

**2.** `x^(5−2) y^(2−5) = x^3 y^(−3)` → **`x^3 / y^3`**

**3.** `27^(2/3) = (³√27)^2 = 3^2` → **`9`**

**4.** `32^(−2/5) = 1 / 32^(2/5) = 1 / (⁵√32)^2 = 1 / 2^2` → **`1/4`**

**5.** `(2a^2 b)^3 = 8a^6 b^3`; divide by `4a^3 b^2`: `8/4 · a^(6−3) · b^(3−2)` → **`2a^3 b`**

**6.** `6x^2 + 15x − 4x − 10` → **`6x^2 + 11x − 10`**

**7.** `(2x)^2 − 2(2x)(5) + 25` → **`4x^2 − 20x + 25`**

**8.** Two numbers ×20, +(−9): −4 and −5 → **`(x − 4)(x − 5)`**

**9.** Difference of squares → **`(2x − 5)(2x + 5)`**

**10.** `a·c = −18`; split with +9, −2: `6x^2 + 9x − 2x − 3 = 3x(2x+3) − 1(2x+3)` → **`(3x − 1)(2x + 3)`**

**11.** `√72 = √(36×2)` → **`6√2`**

**12.** `3√3 + 5√3 − 2√3` → **`6√3`**

**13.** `6 − 3√5 + 2√5 − 5 = (6 − 5) − √5` → **`1 − √5`**

**14.** `14/√7 = 14√7/7` → **`2√7`**

**15.** Multiply by conjugate `(3 − √2)`: denominator `9 − 2 = 7` → **`(3 − √2)/7`**

## Part B

**16.** `(x − 2)(x − 5) = 0` → **`x = 2` or `x = 5`**

**17.** `(x + 7)(x − 4) = 0` → **`x = −7` or `x = 4`**

**18.** `a·c = −6`, split +6, −1: `(2x − 1)(x + 3) = 0` → **`x = 1/2` or `x = −3`**

**19.** `(3x − 4)(3x + 4) = 0` → **`x = ±4/3`**

**20.** `(x + 4)^2 − 16 + 3 = (x + 4)^2 − 13` → vertex **`(−4, −13)`**

**21.** `(x − 5/2)^2 − 25/4 + 2 = (x − 5/2)^2 − 17/4` → vertex **`(5/2, −17/4)`**

**22.** `3(x^2 + 4x) − 1 = 3[(x + 2)^2 − 4] − 1 = 3(x + 2)^2 − 13` → vertex **`(−2, −13)`**

**23.** `a=2, b=−5, c=−1`; disc `= 25 + 8 = 33`; `x = (5 ± √33)/4` → **`x = (5 ± √33)/4`**

**24.** Equal roots ⇒ disc `= 0`: `k^2 − 64 = 0` → **`k = ±8`**

**25.** Two distinct real roots ⇒ disc `> 0`: `9 − 8k > 0 → k < 9/8`. Also need `k ≠ 0` (else not quadratic). → **`k < 9/8, k ≠ 0`**

**26.** disc `= (−3)^2 − 4(1)(5) = 9 − 20 = −11 < 0`, so no real roots. **Shown.** ∎

**27.** Let `u = x^2`: `u^2 − 13u + 36 = (u − 4)(u − 9) = 0 → u = 4, 9`; back-sub → **`x = ±2, ±3`**

**28.** Let `u = √x`: `u^2 − 7u + 10 = (u − 2)(u − 5) = 0 → u = 2, 5`; `√x = 2 → x = 4`, `√x = 5 → x = 25` → **`x = 4` or `x = 25`**

**29.** Roots: `(x − 4)(x + 2) = 0 → x = 4, −2`. y-intercept `(0, −8)`. Vertex: `(x − 1)^2 − 9 → (1, −9)`. → **roots `−2, 4`; y-int `(0, −8)`; vertex `(1, −9)`, U-shape.**

**30.** Equal roots ⇒ disc `= 0`: `(k + 3)^2 − 16k = k^2 + 6k + 9 − 16k = k^2 − 10k + 9 = (k − 1)(k − 9) = 0` → **`k = 1` or `k = 9`**
