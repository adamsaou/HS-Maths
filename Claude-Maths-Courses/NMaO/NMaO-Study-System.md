# NMaO Study System

<span class="nmao-badge nmao-study">STUDY PROTOCOL</span>

> [!important] This is the canonical system
> Codex should check this file and [[NMaO-Study-Hub]] before guiding a new session. The system changes only when we deliberately agree on an improvement.

## Purpose

Build olympiad ability progressively from TC to 1BAC, while maintaining exam readiness and clean mathematical writing.

## Session lifecycle

### 1. Prepare

- Read [[NMaO-Study-Hub]].
- Check [[NMaO-Corrections]] for overdue review.
- Choose one objective, not an unrealistic list of topics.
- Decide whether the session is **study**, **training**, **testing**, or **correction**.

### 2. Attempt

- Read the entire problem carefully.
- Define variables and constraints.
- Try independently before requesting help.
- For a normal problem, spend 30-45 minutes before asking for a hint.
- For a timed paper, use the official time and do not consult notes.

### 3. Get help progressively

Codex must use this hint ladder unless the student asks for a full solution:

1. Restate the goal and identify the topic.
2. Give a small observation.
3. Give a strategic hint.
4. Give a key lemma or next step.
5. Give a complete solution only on request or after a serious attempt.

### 4. Correct

Every attempted problem receives a correction record in [[NMaO-Corrections]]:

- What was correct
- The first incorrect step
- The missing idea
- A clean proof
- One transfer problem or review task

Use LaTeX for mathematics, for example $a^2+b^2 \ge 2ab$ and:

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}.
$$

### 5. Close the session

- Record what was learned.
- Record the next action.
- Update the relevant paper, topic, correction, and review checkboxes.
- Never mark a topic mastered just because the solution was understood.

## Weekly rhythm

| Session | Purpose | Typical work |
|---|---|---|
| A | Learn | One technique with examples |
| B | Focused training | 3-5 problems on that technique |
| C | Mixed training | Problems from different topics |
| D | School support | Current curriculum and weak prerequisites |
| E | Test or correction | Timed paper, partial paper, or deep review |

If there is less time, keep the order and reduce the number of problems rather than skipping correction.

## Chronological paper strategy

The archive is eventually studied from 2017 toward 2026, but papers are not the curriculum itself. We learn the general tools first, use unseen papers as mocks, then study papers at the level supported by the evidence.

### Curriculum before papers

- Build the core TC toolkit across algebra, number theory, geometry, combinatorics, and proof-writing.
- Train each topic on simple and intermediate problems before touching a target paper.
- Use the NMaO archive mainly as diagnostic tests, level checks, and later complete-paper practice.
- Retake a paper only after enough time has passed and the relevant tools have been learned.

### Training mode: 2017-2018

- Use this level as the first paper benchmark after the TC foundation block.
- Work on two problems per session at first, then complete full timed mocks.
- Allow up to 45-60 minutes per problem during training.
- Stop and record the key obstacle if no progress is being made.
- Correct before advancing.

### Transition mode: 2018-2021

- Begin with selected timed papers or timed sections.
- Keep a strict record of time spent per problem.
- Complete a correction session after each paper.

### Exam mode: 2022-2026

- Use the official duration.
- Work without help or notes.
- Treat the result as promotion evidence.
- Revisit older corrections before the next exam.

Taking a long time on an unfamiliar problem is not itself failure. The evidence we track is the quality of the attempt, the first useful idea, the correction, and whether the method transfers later.

## Appropriate-level rule

We move upward only when two or three recent mocks show that the current level is becoming manageable. A target is not promoted merely because its year is later. Difficulty, proof quality, time management, and recurring errors all matter.

## Proof standards

A final solution must state the main idea, justify non-obvious steps, respect all restrictions, and answer every part of the problem. Numerical experimentation is useful for discovery but is not a proof.

## Promotion system

### TC foundations

Build fluency in factorisation, elementary inequalities, divisibility, congruences, similarity, cyclic geometry, counting, and induction.

### Stronger TC

Use recent TC papers under time pressure. Prioritise proof completeness, problem selection, and efficient first observations.

### 1BAC

Add advanced inequalities, polynomials, floor functions, Diophantine equations, harder geometry, and equality cases.

## Non-negotiable rules

- Attempt before seeing a solution.
- Corrections are part of studying, not optional paperwork.
- Use exact mathematical language and LaTeX.
- Put all mathematical LaTeX, equations, and proof explanations in [[NMaO-Live-Study-Notes]] so they can be read comfortably in Obsidian.
- Keep chat replies plain-text and use them mainly for instructions, feedback, and links to the notes.
- Keep a record of repeated errors.
- Revisit failed problems after a delay.
- Increase difficulty only when the evidence supports it.
